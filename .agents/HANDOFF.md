# HANDOFF — ClipShelf
Обновлено: 2026-10-14 15:38

## Цель
Завершить обновление брендинга ClipShelf (иконка Вариант 4 во весь рост без белого фона, UI настроек в стиле Windows 11 Fluent).

## Сделано
- Выбран и финализирован **Вариант №4** (Fluent 2 Сквиркл с зажимом буфера обмена и акриловой полкой).
- Полностью удален белый фон холста: за пределами скругленного контура обеспечена 100% альфа-прозрачность.
- Иконка скадрирована и отмасштабирована **во весь рост** (full-bleed с субпиксельным антиалиасингом скруглений).
- Сгенерированы мастер-исходники:
  - `assets/app_icon.png` (512x512, прозрачный фон, полный размер);
  - `assets/app.ico` (полный набор 16, 24, 32, 48, 64, 128, 256 с 32-bit альфа-каналом);
  - Мастер-копия концепта сохранена в `assets/concept4_source.jpg`.
- В `src/MainForm.cs` оптимизирована отрисовка шапки:
  - Пути к иконке теперь надежно определяются относительно сборки (`typeof(MainForm).Assembly.Location`);
  - Добавлена отрисовка `headerIconBmp` в режиме `HighQualityBicubic` и `PixelOffsetMode.HighQuality` (36x36 в шапке окна смотрится кристально четко).
- Обновлен `build.bat` для автоматической синхронизации `app.ico` и `app_icon.png` в папку `dist`.
- Проект успешно собран (`build.bat`) без ошибок и предупреждений.

## Решения и договорённости
- Вариант 4 утвержден как официальный логотип ClipShelf.
- Белый фон удален, края сглажены прозрачным антиалиасингом под любую системную тему Windows 11.
- .NET 4.0 / C# 5 синтаксис (без string interpolation `$""` и expression-bodied members).

## Ключевые файлы
- `assets/app.ico`, `assets/app_icon.png` — утвержденная иконка без белого фона
- `assets/convert_icon.ps1` — скрипт генерации прозрачной полноразмерной иконки
- `src/MainForm.cs` — заголовок с плавной отрисовкой иконки
- `dist/ClipShelf.exe`, `dist/PasteImageAsFile.exe` — готовые сборки

## Как проверить
- Сборка: `cmd.exe /c build.bat`
- Запуск настроек: `dist\ClipShelf.exe`
- Запуск службы: `dist\ClipShelf.exe --daemon`
