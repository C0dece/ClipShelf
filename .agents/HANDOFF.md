# HANDOFF — ClipShelf
Обновлено: 2026-10-14 16:54

## Цель
Завершить обновление брендинга ClipShelf (интеграция новой изолированной иконки во все формы приложения, системный трей, контекстное меню Проводника и синхронизация с GitHub).

## Сделано
- Создан метод `Program.GetAppIcon(int targetSize)` для надежной загрузки нужного слоя иконки с авто-определением каталога сборки.
- В `Program.InitTray()` настроена загрузка нативного размера трея (`SystemInformation.SmallIconSize`, 16/24px) без мыльного авто-ресайза Windows.
- Иконка приложения назначена во все дочерние окна:
  - `MainForm` (окно настроек);
  - `ClipboardFlyoutForm` (всплывающее окно `Win+V`);
  - `ItemViewerForm` (окно детального просмотра);
  - `UpdateDialogForm` (диалог обновления);
  - `FolderPromptForm` (диалог создания/переименования папок SuperHub);
  - `SuperHubDockForm` (док-полка).
- В `ShellIntegration.cs` добавлено прямое указание `app.ico` для пунктов контекстного меню Проводника и копирование `app_icon.png` при установке.
- Проект собран (`build.bat`), фоновый демон перезапущен со свежей иконкой в трее.

## В процессе / Следующий шаг
1. Проверить отображение иконки у пользователя в трее Windows и на окнах приложения.
2. При необходимости обновить промо-материалы/скриншоты в `README.md`.

## Решения и договорённости
- Фирменный логотип: изолированный 3D планшет Fluent 2 (хромированный зажим + стеклянная полка с фото и документом) без фоновых подложек.
- Все формы и трей используют единый источник `Program.GetAppIcon()`.
- .NET 4.0 / C# 5 синтаксис (без string interpolation `$""` и expression-bodied members).

## Ключевые файлы
- `assets/app.ico`, `assets/app_icon.png` — изолированная иконка без фона
- `src/Program.cs` — точка входа, `GetAppIcon` и инициализация `trayIcon`
- `src/MainForm.cs`, `src/ItemViewerForm.cs` — окна приложения
- `dist/ClipShelf.exe`, `dist/PasteImageAsFile.exe` — готовые сборки

## Как проверить
- Сборка: `cmd.exe /c build.bat`
- Запуск настроек: `dist\ClipShelf.exe`
- Запуск службы: `dist\ClipShelf.exe --daemon`
